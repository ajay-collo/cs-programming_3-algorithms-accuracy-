 Data Structures and Algorithms Assignment

Hey there. This repository contains my solutions for the C++ Data Structures and Algorithms warm-up assignment covering Questions 1 through 6. Everything was written, tested, and verified on a Linux terminal environment.

What Is Included in the Archive:

    1revLList.cpp (Q1)

    Reverses a singly linked list in linear time O(N) by carefully looping through and flipping the prev, curr, and nextNode pointers so everything points backward.

    2ndquestion.cpp (Q2)

    Uses a standard stack to check whether a string has properly nested and balanced parentheses. Returns true if it is valid, and false otherwise.

    3rdquestion.cpp (Q3)

    Implements a custom dictionary data structure for a finite set that handles search, insertion, and deletion operations in worst-case O(1) time.

    4thquestion.cpp (Q4)

    Converts a Binary Search Tree into a sorted singly linked list in O(N) time using an in-order traversal approach with a tracking pointer.

    5thquestion.cpp (Q5)

    Efficiently figures out if a search string can be built by cutting out characters from a magazine using a character frequency count array in linear time.

    6thquestion.cpp (Q6)

    Finds the largest number in a circularly shifted sorted array in O(1) time by directly mapping and accessing the target index.

    warm-up assignment-ss.pdf

    A clean PDF document containing all the execution screenshots and terminal outputs for each program.   
    warm-up assignment-ss.pdf

How to Compile and Run
You can compile and run any of these files using the GNU compiler via your terminal:

Step 1: Compile
g++ filename.cpp

Step 2: Run
./a.out
